# Hello Copilot 使用说明

## 快速开始

### 1. 安装扩展
1. 下载 `.vsix` 文件
2. 在 VS Code 中按 `Ctrl+Shift+P` (Windows/Linux) 或 `Cmd+Shift+P` (macOS)
3. 输入 "Extensions: Install from VSIX..."
4. 选择下载的 `.vsix` 文件

### 2. 获取 Cursor 用户信息
1. 按 `Ctrl+Shift+P` (Windows/Linux) 或 `Cmd+Shift+P` (macOS)
2. 输入 "获取 Cursor 用户信息"
3. 选择命令执行

### 3. 查看输出
- 用户信息会以弹窗形式显示
- 详细信息会记录在扩展输出中
- 按 `Ctrl+Shift+U` 查看输出面板，选择 "Hello Copilot"

## 功能列表

- ✅ **获取 Cursor 用户信息** - 支持多种信息源
- ✅ **Sonar 代码质量分析** - 自动执行代码扫描
- ✅ **单元测试执行** - Maven 测试和覆盖率报告
- ✅ **项目管理** - 自定义项目浏览器
